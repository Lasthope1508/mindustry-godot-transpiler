# Report — N2123: C06 pause gate (2026-11-11)

## What was built

The live loop had no pause: `process_tick` ran `Time.update` and every sim on every frame no matter what, so there was no way to freeze the game. Java gates the whole game update on the pause state: `Logic.update` (Logic.java:507) runs the tick, `Time.update` and `updateEntities` only inside `if(!state.isPaused())`, and `GameState.isPaused` (GameState.java:93-95) is `state == State.paused` (states paused, playing, menu; set with `GameState.set(State)`, GameState.java:60-62). The port keeps the pause as the game's `paused` flag on the root bridge, reads it through the pure `source_game_loop_paused_state`, and `process_tick` returns before `Time.update` and before any sim while it is set — so a paused game advances nothing at all: no drill time, no pump warmup, no belt movement, no core deliveries, and `MindustryTime.time` frozen.
