## Source

Multi-press size 3 (Blocks.java:1059, `size = 3;`);
`occupied_cells` centres odd sizes. The N2394 proof placed the
press centred at ring cell (30,20) with footprint (29..31,
19..21): it covers ring cells (30,19) = ring **4**, (30,20) =
ring 5, (30,21) = ring 6 — AND overlaps the origin (unloader)
footprint at the x=29 column. The proof asserted fill values
only at indices 5/6/0, so the fill keys still pass; only the
live tick is wrong. Worker-N2406 found the defect in
advances-23 (simulation); this slice verifies it independently
and fixes the proof.

exact GDScript semantics — `dump_liquid_state` routing gate +

reproduces the OLD proof values exactly (cdump 7, 37.5/12.5/

cause.

**Fix** (`C07PayloadUnloaderDumpNeighbourLiveFillProof.gd`
only; no `.tscn` change — placement is script-driven): press
re-centred to `Vector2i(31, 20)` — footprint (30..32, 19..21)
covers exactly ring 4/5/6 with ZERO origin overlap (values
identical to truth: cdump 5, 43.75/6.25/43.75); ring-4 fill
asserts added in both fill keys (5.0 / 60.0 / accepts /
canDump, liquid + item); live-tick cdump 7→5.

**Finding beyond the brief's cdump bullet:** the defect also

**Pin test:** N2409 static pins appended to the existing
