## Ownership and actual API boundary

`SourceConveyorRuntimeState` gains `source_conveyor_remove_stack_state` (N2056), `source_conveyor_accept_stack_state` (N2057) and `source_conveyor_handle_stack_state` (N2058).

- **N2056 removeStack.** `source_conveyor_remove_stack_state(ids, xs, ys, len, item_id, amount, item_count_before) -> Dictionary`. noSleep runs first (recorded). For each of `amount` iterations, scans from the front for the first `ids[i] == item_id` and removes it via the N2054 queue removal; one removal per iteration at most. Then the items module loses the same count (`items.remove(item, removed)`). Result keys: `ids_after, xs_after, ys_after, len_before, len_after, removed, item_count_after, no_sleep_called`.
- **N2057 acceptStack.** `source_conveyor_accept_stack_state(minitem, item_space, amount) -> Dictionary`. Returns `min(int(minitem / itemSpace), amount)` — the free slots in item-space units, truncated, capped by the request. Result keys: `accepted, free_slots, reason` (accepted, invalid_item_space).
- **N2058 handleStack.** `source_conveyor_handle_stack_state(ids, xs, ys, len, capacity, item_id, amount, item_space, item_count_before) -> Dictionary`. Clamps the amount by free capacity (`min(amount, capacity - len)`), then inserts from `i = amount - 1` down to 0 via the N2053 queue add at index 0, setting `xs[0] = 0`, `ys[0] = i * itemSpace`, `ids[0] = item` and adding one to the items module per insertion — so the finished stack sits spaced itemSpace apart from ys 0, with the oldest items deepest. noSleep runs after. Result keys: `ids_after, xs_after, ys_after, len_before, len_after, inserted, item_count_after, no_sleep_called, reason` (inserted, at_capacity, empty_request).
