## What this slice does

- **N2069 `SourceConveyorRuntimeState.source_conveyor_advance_state(ids, xs, ys, len, speed, delta, time_scale, aligned, next_minitem, blendbits, clog_heat_before) -> Dictionary`** — the updateTile movement loop, without the pass (the pass is the wrapper's handoff via the already-bound N2052 pass). It moves each item from the last index down to 0, clamped by the item ahead (`nextpos = ys[i+1] - itemSpace`, or 100 - itemSpace for the front item) and by `nextMax` (1.0, or `1f - max(itemSpace - next_minitem, 0)` when aligned), drifts x toward 0, scans mid/minitem, computes clogHeat, and reports whether the front item reached the exit. An empty belt at time scale 1 sleeps (`reason: empty_sleep`, `no_sleep_called: false`, clog heat 0). Result keys: `ids_after, xs_after, ys_after, len_after, mid, minitem, pass_ready, pass_item_id, clog_heat, no_sleep_called, reason` (advanced, empty_sleep).
- **N2070 `SourceFactoryRuntimeState.source_factory_advance_conveyors_state(game, conveyor_cells, delta) -> Dictionary`** — the live-loop belt-advance step. It resolves each belt's queue (N2065), rotation, team and speed (from the catalog block's `properties["speed"]`, default 0.03), advances the belts front-to-back (the caller gives the cells in that order, closest to the core first, so a belt hands off to a belt that already advanced this frame), and hands the ready item to the next belt (via the N2060/N2061 accept/handle-for-cell hooks, with `source_block_rotate = true` for the conveyor block) or to the core (via the game's `source_core_accept_item` / `source_core_handle_item` methods, already bound in `SourceCoreInventoryRuntimeState`). A passed item is removed from its belt's queue (N2054) and the next belt's queue is updated from the handle result. It writes back only the queues that actually changed — an empty belt that stayed empty gains no stored queue meta. `simulate_factory` calls it after the dump step, with the conveyor cells from `SourcePlayableScenarioDefaults.conveyor_cells()` reversed to front-to-back. Result keys: `results_by_cell, passed_count, reason` (advanced, no_conveyors).
