## Ownership and actual API boundary

- **N2065 `SourceConveyorRuntimeState.source_conveyor_queue_for_cell_state(game, cell) -> Dictionary`** — the queue read: the sprite is resolved via `game.call("block_sprite_at_cell", cell)`. No sprite → the empty queue with `found=false`, reason `no_sprite`. A sprite with no stored queue → the empty queue with `found=true`, reason `no_queue` (a real belt with nothing on it). A sprite with a stored queue → its `ids`/`xs`/`ys`/`len` with `found=true`, reason `queue`. Result keys: `ids, xs, ys, len, found, reason`. The function does not check the block type: a sprite of another block (e.g. the drill at (7,8)) reads as an empty queue with `found=true`.
- **N2066 `SourceConveyorRuntimeState.source_conveyor_set_queue_for_cell_state(game, cell, queue) -> Dictionary`** — the queue write: the queue dict is stored on the sprite meta `source_conveyor_queue` (`SOURCE_CONVEYOR_QUEUE_META_KEY`). No sprite → `stored=false`, reason `no_sprite`. Result keys: `stored, reason`.
- **N2067 `SourceConveyorRuntimeState.source_conveyor_queues_for_cells_state(game, cells) -> Dictionary`** — the resolver: N2065 over each cell, keeping only cells with a sprite (`found=true`). Cells without a conveyor are left out, which is exactly the dump step's fail-closed rule (its accept hook rejects cells missing from `queues_by_cell`). Result keys: `queues_by_cell, found_count, reason` (resolved, none_found).
