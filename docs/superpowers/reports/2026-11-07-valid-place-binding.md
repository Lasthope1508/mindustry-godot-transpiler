## Ownership and actual API boundary

`SourceBlockGeometry` gains `source_valid_place_footprint_cell_state` (N2041) and `source_valid_place_ignore_units_state` (N2042). `PortGame` gains `source_valid_place_state` (N2043). The N2033 setBlock binding in `SourceWorldTerrainRuntimeState` gains one line: the entity init stores the placement rotation on the Building sprite meta (`SOURCE_BUILD_ROTATION_META_KEY`), so the same-block check reads real state instead of a caller guess.

- **N2041 per-cell check.** The world Tile is resolved at the footprint cell; a null tile fails (`cell_missing`). In Java order: size-2 darkness (`darkness`); staticFog + fog + undiscovered (`fog`); deep floor without floating/requiresWater/placeableLiquid (`deep_floor`); derelict repair off with a derelict-team Building (`derelict`); same block + same rotation + rotate, except a non-derelict team replacing a derelict same block (`same_block_rotation`); `Tile.interactable` from `Teams.canInteract`, evaluated from the team metas (`not_interactable`); non-placeable floor without ignoreBuildDarkness (`solid_floor`); payload replacement of a non-alwaysReplace block (`payload_replace`); canReplace/canBeReplaced/derelict-same-type plus bounds containment (`cannot_replace`); requiresWater without a water liquidDrop (`requires_water`). `canBeReplaced` collapses into `canReplace` because `Building.canBeReplaced(other)` is `other.canReplace(block)`; ConstructBuild replacement is false because the runtime has no build under construction. Result keys: `cell, valid, reason`.
- **N2042 validPlaceIgnoreUnits.** Null type (`type_null`); visibility gate from the caller-supplied rules dict and block flags (`not_visible`); core protection from the caller-supplied cores registry — polygon mode takes the closest protected core, radius mode blocks any enemy protected core within buildRadius + tilesize, with cell-center distances in pixels (`core_protection`); null tile (`tile_missing`); canPlaceOn hook, defaulting to the Block default true (`can_place_on`); floor blocks return the overlay/floor comparison directly (`floor_already`); darkness (`darkness`); shallows via footprint-plus-ring floors (`no_shallows`); the footprint loop through N2041, returning the first failing cell and reason; place-range check via the enemy-overlap hook (`enemy_overlap`). Result keys: `valid, reason, cell`.
- **N2043 PortGame entry.** `source_valid_place_state` runs N2042, then `checkNoUnitOverlap`: a solid or solidifes block with a hook reporting an overlap fails (`unit_overlap`); a null hook means no overlap, because the runtime has no unit system yet.

## What is real and what is supplied

Real runtime state evaluated by the binding: the world Tile store (block, floor, overlay, build, team), the Building team and rotation metas, block size from the catalog, footprint cells from `occupied_cells`, and the `canReplace` group/size/subclass logic from flag values. Caller-supplied, each with a Java default when absent: `block_flags` / `floor_flags` lookup dictionaries (Block/Floor fields the catalog does not export — rotate, solid, floating, requiresWater, placeableLiquid, ignoreBuildDarkness, alwaysReplace, privileged, replaceable, quickRotate, group, group_any_replace, subclass, isFloor, isOverlay, environmentBuildable, isPlaceable, isVisible, offset, placeOverlapRange, isDeep, isLiquid, liquidDrop, placeableOn); `rules_state` (editor, waves, waveTeam, derelictRepair, polygonCoreProtection, staticFog, fog, placeRangeCheck — Rules.java defaults); `cores_state` (cores with cell/team/protectCores, buildRadius 400, tilesize 8). Hooks, each defaulting honestly when absent: `can_place_on_hook` (Block default true), `darkness_hook` (0, no darkness data), `fog_discovered_hook` (undiscovered, only called when fog is on), `enemy_overlap_hook` (no overlap, only called when placeRangeCheck is on), `unit_overlap_hook` (no overlap, no unit system yet). The proof supplies the verified upstream flag values for conveyor (rotate, transportation/anyReplace), drill (solid, drills), core-shard (solid), air (alwaysReplace), stone and deep-water floors, and a Drill.canPlaceOn hook that reads ore overlays.
