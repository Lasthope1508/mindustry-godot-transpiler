# Drill bridge dominant-item binding — N2071

Date: 2026-11-07. Parent: `f28a078`. Sequential C01–C12 goal, C02 batch after N2069–N2070. This batch makes the drill runtime bridge resolve the actual dominant item from the drill frame (the ore scan, Drill.onProximityUpdate) instead of reading the game-global `drill_output_item_id` (Drill.java:270–278, 287–298). - **N2071 `PortGame.source_drill_runtime_state(seconds) -> Dictionary`** — the drill runtime bridge (in `SourceDrillRuntimePortBridge.gd`; the owner is `PortGame.*` per the PortBridge discovery rule).
