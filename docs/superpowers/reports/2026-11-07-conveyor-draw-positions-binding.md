## What this slice does

**N2076 `SourceConveyorRuntimeState.source_conveyor_item_draw_positions_state(queue, center, rotation, tilesize) -> Dictionary`** — for each item in the queue (clamped to the shortest of len/ids/xs/ys), computes its world position from the Java draw formula: `along = Vector2(tilesize, 0).rotated(angle)`, `lateral = Vector2(-tilesize/2, xs[i]*tilesize/2).rotated(angle)`, `x = center.x + along.x * ys[i] + lateral.x`, `y = center.y + along.y * ys[i] + lateral.y`. Java is y-up and Godot is y-down, so the rotation angle is negated (`angle = deg_to_rad(rotation * -90)`). Result keys: `positions` (one `{item_id, x, y}` per queue item, in queue order), `count`.
