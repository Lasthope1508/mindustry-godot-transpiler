## Ownership and actual API boundary

`SourceConveyorRuntimeState` gains `source_conveyor_accept_item_state` (N2050), `source_conveyor_handle_item_state` (N2051) and `source_conveyor_pass_state` (N2052).

- **N2050 acceptItem.** `source_conveyor_accept_item_state(len, capacity, facing_direction, rotation, minitem, item_space, source_block_rotate, next_is_source) -> Dictionary`. Capacity guard, facing null guard (facing_direction −1), `direction = |facing_direction − rotation|`, arms `(direction == 0 && minitem >= itemSpace) || (direction % 2 == 1 && minitem > 0.7)`, and the `!(source.block.rotate && next == source)` refusal. Result keys: `accepted, direction, reason` (accepted, at_capacity, no_facing, wrong_direction, rotate_loop). The facing direction (from the source facing edge to the conveyor tile) is computed by the caller with the existing `tile_relative_cardinal_state`; the multiblock facing-edge clamp is a later slice.
- **N2051 handleItem.** `source_conveyor_handle_item_state(len, capacity, facing_direction, rotation, mid, item_id, item_count_before) -> Dictionary`. Capacity guard (no noSleep, no intake); otherwise `ang = facing_direction − rotation` (not absolute — Java's handleItem does not take the absolute value here), `x` from the ang arms, straight (`|ang| == 0`) inserts at index 0 with y 0, side inserts at mid with y 0.5, `noSleep()` runs on intake. Result keys: `accepted, index, x, y, len_after, item_count_after, no_sleep_called, reason` (accepted, at_capacity). The caller applies the array shift (`add(0)` / `add(mid)`) at the returned index.
- **N2052 pass.** `source_conveyor_pass_state(item_id, next_present, next_same_team, next_accepts_hook, next_handle_hook) -> Dictionary`. Guards (null item, no next, wrong team, next rejects via hook); a missing handle hook fails closed with reason `no_handle` (the dump-batch precedent — a transfer that cannot complete is not reported as passed). On success the handle hook runs. Result keys: `passed, item_id, handle_called, reason` (passed, null_item, no_next, wrong_team, next_rejects, no_handle).
