# Two-Drill gate binding — N2073

Date: 2026-11-07. Parent: `5041e7e`. Sequential C01–C12 goal, C02 batch after N2072. This batch makes the live loop dump every drill's output when the dump timer fires (the two-Drill gate): `simulate_factory` calls the new dump-all step instead of dumping only the primary drill. Each drill dumps from its own inventory via the N2072 per-drill dump, so the secondary's output now reaches a belt instead of accumulating in its frame forever. It does not add the queue-to-sprite sync, it does not accept C02 as a domain or clean-checkout reproducibility.

## What this slice does

- **N2073 `SourceFactoryRuntimeState.source_factory_dump_all_drill_outputs_state(game, should_dump) -> Dictionary`** — the live-loop dump step. When `should_dump` is false it returns early with reason `timer_not_fired` and no results. Otherwise it enumerates the drill buildings (via `placed.source_unique_buildings_state`, keeping only sprites with a drill frame meta and an `origin_cell`), resolves each drill's dominant item from its frame (via `source_dominant_item_name_state`), and dumps it through the N2072 per-drill dump. Result keys: `results_by_cell` (the per-drill dump results keyed by drill cell), `dumped_count`, `reason` (`timer_not_fired` / `no_drills` / `dumped` / `none_dumped`). All drills share the primary's SHOULD_DUMP — they share dumpTime 5 and were placed at bootstrap.
- **`simulate_factory` now calls the dump-all step** instead of the primary-only dump. The old primary-only call (`source_factory_dump_drill_output_state(game, drill_cell, drill_output_item_id)`) is removed from the live loop; the old entry still exists as the N2072 delegate for direct callers and the N2068 proof. The `test_playable` pin that asserted the old primary-only wiring (`test_port_game_delegates_factory_simulation_apply_state_to_module`) now pins the new dump-all call and asserts the old call is gone — the same class of stale-pin update as the N2069 batch.
