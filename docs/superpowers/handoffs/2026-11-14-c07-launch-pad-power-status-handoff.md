- Why: the launch pad has NO driver at all — no `SourceLaunchPad*` file exists in godot-mindustry/src/game, it extends Block, not a factory or crafter, so no existing driver matches it, and no frame key exists for it, so the N2142 stamp never reaches a launch-pad frame.
